# OctoAcme Project Management Docs

## Overview
OctoAcme follows a structured, lightweight project management approach designed for cross-functional teams delivering product features and services. Our methodology prioritizes customer value, iterative delivery, clear ownership, and data-informed decisions.

## OctoAcme Project Lifecycle

Every OctoAcme project follows this five-phase lifecycle:

1. **Initiation** — Validate business need, align stakeholders, establish success criteria
2. **Planning** — Break work into shippable increments, identify dependencies, define milestones
3. **Execution** — Build, test, and iterate through daily standups and regular demos
4. **Release** — Deploy to production with confidence and measure impact
5. **Retrospective** — Capture learnings and drive continuous improvement

## Core Roles

OctoAcme projects require clear ownership across three core roles. Learn more in [Roles and Personas](./octoacme-roles-and-personas.md):

- **Project Manager** — Coordinates delivery, manages schedules and risks, ensures communication and alignment
- **Product Manager** — Defines outcomes, prioritizes work, measures success against metrics
- **Developers & QA** — Implement features, validate quality, collaborate on design and testability
